### Mixed Code and RTL Comments

```python
# هذه دالة لحساب المتوسط - This function calculates the average
def حساب_المتوسط(الأرقام):
    """
    تحسب هذه الدالة المتوسط الحسابي لقائمة من الأرقام
    This function calculates the arithmetic mean of a list of numbers

    المعاملات:
        الأرقام: قائمة من الأرقام العشرية

    القيمة المرجعة:
        المتوسط الحسابي
    """
    المجموع = sum(الأرقام)
    العدد = len(الأرقام)
    return المجموع / العدد if العدد > 0 else 0
```

### Persian Text - متن فارسی

هوش مصنوعی شاخه‌ای از علوم رایانه است که هدف آن ایجاد سیستم‌هایی است که قادر به شبیه‌سازی رفتار هوشمند انسانی هستند. در سال‌های اخیر، این حوزه با پیشرفت‌های چشمگیری در فناوری‌های یادگیری عمیق مواجه شده است. مدل‌های زبانی بزرگ اکنون قادر به درک و تولید متون در سطحی نزدیک به عملکرد انسانی هستند.

نکته مهم: متن فارسی از نویسه‌های عربی استفاده می‌کند اما زبان فارسی حروف اضافی مانند پ، چ، ژ و گ دارد که در الفبای عربی وجود ندارند. این تفاوت می‌تواند در تشخیص زبان مشکل ایجاد کند.
