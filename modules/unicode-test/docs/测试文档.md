# 测试文档 - Test Document

## 目的

本文档用于测试RAG系统对中文Markdown文件的处理能力。文件名本身包含中文字符，这是对文件路径处理的一个重要测试点。

## 常见问题

### 编码问题

在处理中文文本时，最常见的问题包括：

1. **乱码（mojibake）**：当系统用错误的编码格式读取文件时，中文字符会显示为乱码。例如，UTF-8编码的「你好」如果用Latin-1解码，会显示为「ä½ å¥½」。

2. **截断问题**：一个UTF-8编码的中文字符占用3个字节。如果文本按固定字节数截断，可能会把一个字符切成两半，导致无效的字节序列。

3. **排序问题**：中文的排序规则（collation）与英文不同。按Unicode码点排序和按拼音排序会得到不同的结果。例如：
   - 按码点：一 < 万 < 三 < 中
   - 按拼音：三(sān) < 万(wàn) < 一(yī) < 中(zhōng)

### 分词挑战

中文分词是自然语言处理中的基础任务。以下是一些经典的分词歧义案例：

| 原文 | 分词方式A | 分词方式B | 说明 |
|------|----------|----------|------|
| 南京市长江大桥 | 南京市/长江大桥 | 南京/市长/江大桥 | 地名歧义 |
| 研究生命的起源 | 研究/生命/的/起源 | 研究生/命/的/起源 | 词边界歧义 |
| 乒乓球拍卖完了 | 乒乓球拍/卖完了 | 乒乓球/拍卖/完了 | 组合歧义 |
| 下雨天留客天留我不留 | 多种断句方式 | 标点不同意义不同 | 古文歧义 |

## 测试数据

以下是用于RAG检索测试的示例段落：

> 人工智能（Artificial Intelligence，简称AI）是计算机科学的一个分支，它致力于创建能够模拟人类智能行为的系统。近年来，随着深度学习技术的突破性进展，AI在图像识别、自然语言处理、语音合成等领域取得了显著成果。大型语言模型（Large Language Model，LLM）的出现更是开创了人机交互的新范式，使得机器能够理解和生成自然语言文本，极大地提升了信息处理和知识获取的效率。

> 检索增强生成（Retrieval-Augmented Generation，RAG）是一种结合了信息检索和文本生成的技术框架。它通过在生成阶段引入外部知识库的检索结果，有效缓解了大型语言模型的幻觉问题，提高了回答的准确性和可靠性。RAG系统的核心组件包括：文档加载器、文本分割器、向量化模型、向量数据库和语言模型。
